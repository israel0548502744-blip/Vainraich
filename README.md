# הכספים שלי — ניהול כספים אישי ל-iPhone ול-Android

אפליקציה נייטיב בעברית — SwiftUI לאייפון ו-Jetpack Compose לאנדרואיד — שעונה על: כמה כסף יש לך באמת, כמה צפוי להיכנס, כמה אתה חייב, ואיך זה ייראה בעתיד.

## התקנה על אנדרואיד (חינם, בלי Mac)
1. מורידים את הקובץ `app-release.apk` לטלפון (מהשיחה, או מ-GitHub ← Actions ← Android ← Artifacts ← apk).
2. פותחים אותו. בפעם הראשונה אנדרואיד ישאל אם לאפשר "התקנה ממקור לא ידוע" לאפליקציה שממנה פתחת (Chrome / קבצים) — מאשרים.
3. מתקינים ופותחים את "הכספים שלי".
4. עדכונים: מתקינים את ה-APK החדש מעל הישן — הנתונים נשמרים (אותה חתימה).

> Google Play Protect עשוי להציג אזהרה כי האפליקציה לא מהחנות — זה צפוי לאפליקציה אישית. אפשר לבחור "התקנה בכל זאת".

**סטטוס:** שלב 1. מנוע החישובים וקריאת המסמכים עובדים ונבדקו (48 בדיקות). האפליקציה נבנית ב-CI.

## מה יש באפליקציה
- **בית** — כסף זמין בפועל, נפרד לגמרי מכסף צפוי, חובות אליי והתחייבויות. נוסחה ברורה: זמין + צפוי להיכנס − צפוי לצאת = יתרה חזויה. כולל גרף תחזית, תשלומים קרובים ואזהרה על יתרה שלילית.
- **יומן** — אירועים עם הכנסה/הוצאה צפויה, סטטוס תשלום בצבעים, תצוגת חודש/שבוע/יום, חיבור ליומן האייפון.
- **תנועות** — הזנה ידנית, חיפוש וסינון, תשלומים קבועים, צירוף קבלה, אישור תנועות ממתינות.
- **חובות** — מי חייב לי ולמי אני חייב, תשלומים חלקיים, היסטוריה לכל אדם, תזכורות איחור.
- **חשבונות** — בנק, מזומן, ביט, אשראי (בלי ספירה כפולה), חיסכון; עדכון יתרה לפי הבנק.
- **דוחות** — חודשי, מגמות, קטגוריות, מקורות הכנסה, שיעור גבייה; ייצוא CSV ו-PDF.
- **ייבוא ממסמך** — צלם אישור יתרה / דף חשבון / פירוט אשראי / קבלה / צילום ביט, ובינה מלאכותית קוראת אותו. הכול מוצג לבדיקה לפני שמירה.
- **אייפון** — Face ID, התראות, סורק מסמכים, אנשי קשר, Siri ("כמה כסף יש לי בהכספים שלי").

## איך להתקין על האייפון
אפליקציית iPhone חייבת להיבנות עם **Xcode**, שרץ רק על **Mac**.

**אם יש Mac:**
1. מתקינים Xcode מה-App Store ו-XcodeGen (`brew install xcodegen`).
2. `cd ios && xcodegen generate && open Vainraich.xcodeproj`
3. ב-Xcode: Signing & Capabilities → בוחרים Team (Apple ID רגיל מספיק להתקנה אישית ל-7 ימים; חשבון מפתח ב-$99 לשנה — להתקנה קבועה ול-TestFlight).
4. מחברים את האייפון בכבל, בוחרים אותו ולוחצים ▶︎.

**אם אין Mac (Windows):**
- הקוד נבנה אוטומטית ב-GitHub Actions על Mac בענן (כל push), כולל צילומי מסך.
- להתקנה על אייפון בלי Mac צריך חשבון Apple Developer ($99 לשנה) ושירות בנייה בענן (GitHub Actions / Codemagic / Xcode Cloud) שמעלה ל-TestFlight. ההגדרה הזו מתוכננת לשלב 10.
